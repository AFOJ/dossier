<h1 align="center">Dossier</h1>

<p align="center">A local-first resume management tool</p>

## Installation

Requires [Node.js](https://nodejs.org) and [pnpm](https://pnpm.io).

```bash
git clone git@github.com:AFOJ/dossier.git
```

```bash
cd dossier
```

```bash
pnpm install
```

```bash
pnpm start
```

```bash
pnpm test
```
